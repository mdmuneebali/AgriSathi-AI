# AgriSathi AI

AI-powered rice leaf disease screening using deep learning.

## Features
- Rice leaf image upload
- Screening for four disease categories
- Prediction confidence and class probabilities
- Model performance dashboard
- Project information

## Disease Categories
1. Bacterial Blight
2. Blast
3. Brown Spot
4. Tungro

## Technology Stack
- Python
- TensorFlow / Keras
- MobileNetV2
- Streamlit
- NumPy
- Pillow

## Model Evaluation
- Unique dataset images: 4,794
- Training images: 3,355
- Validation images: 719
- Test images: 720
- Held-out test accuracy: 99.44%

## Run Locally

Install dependencies:

    pip install -r requirements.txt

Start the application:

    streamlit run app.py

## Disclaimer
AgriSathi AI is an experimental screening prototype.
Its predictions are not confirmed agricultural diagnoses.
Consult a qualified agricultural expert before making
crop-treatment decisions.
